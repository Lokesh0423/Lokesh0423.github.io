APP TESTS / NODE.JS

The tests passed. The job still would not finish.

Importing the Express app also started a listening HTTP server. Jest reported four passing tests, but an open TCP server handle kept the process alive.

Root cause

The test imports the app to send requests with Supertest. The unconditional app.listen() created an extra server that the test did not close.

Exact fix

if (require.main === module) {
  app.listen(PORT, () => {
    console.log(`Server running on port ${PORT}`);
  });
}
module.exports = app;

Start the server when the file is executed directly. Export the app without opening a listener when tests import it.
