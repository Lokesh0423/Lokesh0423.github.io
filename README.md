# Lokesh Kumar Gaddala — DevOps & Cloud Portfolio

Public portfolio: https://lokesh0423.github.io/

This is a buildless HTML/CSS/JavaScript portfolio deployed by GitHub Pages from the main branch root. No package installation or framework build is required.

## Explore

- Five source-linked project case studies and two AWS labs grouped into a sixth case study.
- Technology filters, text search and deep links to individual projects.
- Architecture walkthroughs, an environment comparison and original pipeline screenshots.
- A metrics explorer and reproducible local smoke-test evidence.

## Evidence

All experience claims are limited to the available source, dated artifacts, or clearly labelled practice history. The local measurement snapshot is a 30-second localhost smoke test, not a production or cloud benchmark. See EVIDENCE.md and the downloadable artifacts under assets/.

## Files

- index.html: page structure and metadata
- styles.css: responsive presentation
- app.js: interactive project case studies and metrics
- assets/: screenshots, measured results and reproduction materials

The previous portfolio remains available in repository history. The existing profile photo has been preserved.
